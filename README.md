# LEVYE 2026

## Put it online (GitHub Pages)
1. Create a new Public repo on github.com.
2. Add file > Upload files: drag in everything in this folder (including `journal`, `images` and `.nojekyll`), then Commit.
3. Settings > Pages > Deploy from a branch > `main` / root > Save.
4. Live at https://USERNAME.github.io/REPO-NAME/ in 1-2 minutes.

## Appear on Google
1. Find and replace `USERNAME` and `REPO-NAME` in every file with your own.
2. Add your URL in Google Search Console (URL prefix) and verify.
3. Submit `sitemap.xml`, then URL inspection > Request indexing.

## New article
Copy a file in `journal/`, edit the text, link it from `index.html`, add it to `sitemap.xml`. Put new photos in `images/`.
